## 1. Анализ языка

`L2 = {aⁿbᵐ : n ≥ 4, m ≤ 3}` - цепочки из не менее чем четырёх символов `a`, за которыми идёт от нуля до трёх символов `b`.

Язык регулярен: распознающему автомату достаточно помнить, сколько прочитано символов `a` (0, 1, 2, 3 или «4 и больше») и сколько символов `b` (от 0 до 3). Это конечное число вариантов, поэтому РВ и РГ для `L2` существуют, и доказательство невозможности их построения не требуется.

Примеры: `aaaa`, `aaaaab`, `aaaabbb` принадлежат языку; `aaab` (меньше четырёх `a`), `aaaabbbb` (больше трёх `b`), `aaaaba` (`a` после `b`), `bbb` (нет `a`) и пустая цепочка ε не принадлежат.

## 2. Часть 1. Регулярное выражение

### 2.1. Полученное РВ

```
aaaaa*(!+b+bb+bbb)
```

В JFLAP `+` - объединение, `*` - замыкание Клини, `!` - пустая цепочка (на графах JFLAP показывает её как λ). Подвыражение `aaaaa*` - это четыре обязательных `a` и любое число дополнительных (`aaaa·a*`), подвыражение `(!+b+bb+bbb)` - от нуля до трёх `b`. В математической записи: `aaaa·a*·(ε + b + bb + bbb)`.

### 2.2. Пошаговое преобразование РВ в КА (Convert → Convert to NFA)

JFLAP начинает с обобщённого графа переходов из двух состояний, дуга между которыми помечена всем выражением. Каждое нажатие **Do Step** раскрывает одну операцию на одной дуге: конкатенацию, замыкание, скобки или объединение. Для раскрытой операции JFLAP добавляет новые состояния и λ-переходы. Преобразование заканчивается, когда все дуги помечены одним символом или λ.

Новые состояния JFLAP ставит поверх уже существующих. Поэтому после каждого шага я перетаскивал их на свободные места: часть `aaaaa*` идёт по верхней строке слева направо, а ветви объединения - по нижним строкам справа налево. На автомат перестановка не влияет, меняется только картинка.

**Исходный граф.** Одна дуга `q0 → q1` с меткой `aaaaa*(λ+b+bb+bbb)`. Сообщение JFLAP: «1 more resolutions needed».

## 3. Часть 2. Регулярная грамматика

### 3.1. Полученная РГ

Праволинейная грамматика `G = ({S, A, B, C, D, E, F}, {a, b}, P, S)`:

```
S → aA
A → aB
B → aC
C → aD
D → aD | bE | λ
E → bF | λ
F → b | λ
```

Нетерминалы `S`, `A`, `B`, `C` порождают четыре обязательных `a`. Нетерминал `D` соответствует состоянию после четырёх `a`: из него можно добавить ещё `a` или начать блок `b`. Нетерминалы `E` и `F` порождают вторую и третью `b`. Правило `D → λ` нужно для цепочек `aⁿ` без `b` при `n ≥ 4`.

### 3.3. Пошаговое преобразование КА в РВ (Convert → Convert FA to RE)

JFLAP строит обобщённый граф переходов в три этапа:

1. объединяет параллельные переходы между одной парой состояний в один переход с меткой-объединением;
2. добавляет пустые переходы `∅` между всеми парами состояний, между которыми переходов нет;
3. удаляет по одному все состояния, кроме начального и допускающего. При удалении состояния `k` метка перехода `i → j` заменяется на `r(i,j) + r(i,k) r(k,k)* r(k,j)`.

Перед преобразованием я расставил состояния по эллипсу в порядке `S → A → B → C → D → E → F → q7`. Так исходные переходы идут по контуру, а пустые переходы `∅` проходят внутри. Состояния удалялись вручную инструментом **State Collapser** в порядке `A, B, C, F, E, D`, чтобы были видны промежуточные графы.

## 4. Часть 3. Нерегулярность языка L28

`L28 = {aⁿbˡaᵏ : n, l, k ≥ 0, k ≠ n + l}`.

**Утверждение.** `L28` не является регулярным языком.

**Доказательство** (от противного, по лемме о разрастании). Пусть `L28` регулярен, и `p ≥ 1` - длина разрастания из леммы.

1. Возьмём цепочку `w = aᵖ b aᵖ⁺¹⁺ᵖ!`, то есть `n = p`, `l = 1`, `k = p + 1 + p!`. Поскольку `k = n + l + p! ≠ n + l`, цепочка `w ∈ L28`, и `|w| ≥ p`.
2. По лемме `w = xyz`, где `|xy| ≤ p`, `|y| ≥ 1` и `xyⁱz ∈ L28` для всех `i ≥ 0`. Так как `|xy| ≤ p`, а первые `p` символов цепочки - это `a`, то `y = aʲ`, где `1 ≤ j ≤ p`.
3. Возьмём `i = 1 + p!/j`. Число `p!/j` целое, потому что `j ≤ p` и `j` делит `p!`. Тогда `xyⁱz = aᵖ⁺ᵖ! b aᵖ⁺¹⁺ᵖ!`, то есть `n' = p + p!`, `l = 1`, `k = p + 1 + p!`.
4. Для этой цепочки `n' + l = p + p! + 1 = k`. Условие `k ≠ n + l` нарушено, значит `xyⁱz ∉ L28`.

Получено противоречие с леммой о разрастании, следовательно, `L28` не регулярен. ∎

Тот же приём можно увидеть на тренажёре **Regular Pumping Lemma** в JFLAP. Языка `L28` в его списке нет, поэтому взят близкий по устройству язык `{aⁿbᵏcⁿ⁺ᵏ}`. Компьютер выбирает `m = 6` и разбиение `x = λ`, `y = a⁶`, `z = c⁶` для цепочки `w = a⁶c⁶`. При `i = 2` получается `a¹²c⁶`, которая языку не принадлежит («YOU WIN»). Как и в доказательстве выше, накачка символов `a` нарушает соотношение длин.

## 5. Вывод

Язык `L2 = {aⁿbᵐ : n ≥ 4, m ≤ 3}` регулярен: для него построены регулярное выражение `aaaaa*(!+b+bb+bbb)` и праволинейная грамматика. В JFLAP пошагово выполнены преобразования РВ → КА, РГ → КА и КА → РВ. Автоматы, полученные из РВ и из РГ, на всех тестовых цепочках дают одинаковые результаты. Обратное преобразование дало выражение `aaaaa*(λ+b(λ+b(λ+b)))`, эквивалентное исходному. Для языка `L28 = {aⁿbˡaᵏ : k ≠ n + l}` по лемме о разрастании доказана нерегулярность.
